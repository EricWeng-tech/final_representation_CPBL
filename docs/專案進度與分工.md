## 一、系統目標（源自 Proposal）

以中華職棒（CPBL）2018–2025 年比賽資料為基礎（CSV 另含 2026 年資料，目前未納入建模），建立可解釋的 AI 決策支援系統，提供以下四項輸出：

| 輸出項目 | 說明 |
|----------|------|
| 比賽勝率 | 預測主隊獲勝的機率（0–100%） |
| 前三大影響因素 | SHAP 解釋：哪三個特徵最左右這場勝負 |
| 攻守前五大關鍵球員 | 本場對勝負影響最大的個別球員 |
| 建議先發陣容 | 針對特定對手，推薦最佳先發配置 |

**主模型：** Random Forest  
**輔助模型：** Logistic Regression + SHAP 可解釋性分析

## 四、已完成的訓練資料說明

### 資料範圍

- **來源：** rebas.tw（CPBL 官方統計平台）

- **訓練集：** 2018–2024（1,947 場）

### 特徵清單（33 個特徵）

**球隊近10場滾動統計（6個）**
- `home/away_win_rate_10`：近10場勝率
- `home/away_runs_scored_10`：近10場平均得分
- `home/away_runs_allowed_10`：近10場平均失分

**先發投手賽前指標（6個）**
- `home/away_starter_ERA`：自責分率
- `home/away_starter_WHIP`：每局被上壘率
- `home/away_starter_FIP`：防守獨立投球指標（排除守備影響）

**牛棚賽前指標（4個）**
- `home/away_bullpen_ERA`：牛棚平均 ERA
- `home/away_bullpen_WHIP`：牛棚平均 WHIP

**打線賽前指標（6個）**
- `home/away_lineup_OPS`：先發打線平均 OPS
- `home/away_lineup_OBP`：先發打線平均上壘率
- `home/away_lineup_SLG`：先發打線平均長打率

**差值特徵（11個，主隊 − 客隊）**
- `win_rate_diff`、`runs_scored_diff`、`run_diff_10`
- `starter_ERA_diff`、`starter_WHIP_diff`、`starter_FIP_diff`
- `lineup_OPS_diff`、`lineup_OBP_diff`、`lineup_SLG_diff`
- `bullpen_ERA_diff`、`bullpen_WHIP_diff`

## 五、待完成功能的技術規格

### 5.1 `predict_game.py` — 單場預測介面

**使用者輸入（依 Proposal 規格）：**
```
主場球隊：樂天桃猿
客場球隊：中信兄弟
主隊先發投手：陳柏清
客隊先發投手：福德尼
主隊打線：王柏融, 陳俊秀, 高國輝, ...（至少 7 人）
客隊打線：林智勝, 陽岱鋼, 朱育賢, ...（至少 7 人）
主隊牛棚：宋文華, 黃子鵬, ...（至少 3 人）
客隊牛棚：鄭浩均, 江國豪, ...（至少 3 人）
```

**系統輸出：**
```
主隊勝率預測：63.2%（Random Forest）/ 61.5%（Logistic Regression）

前三大影響因素（SHAP）：
  1. starter_ERA_diff（主隊先發較佳，ERA 差 1.2）
  2. lineup_OPS_diff（主隊打線 OPS 高出 .045）
  3. win_rate_diff（主隊近10場勝率高出 15%）

攻守前五大關鍵球員：
  攻擊端：王柏融（OPS .921）、高國輝（OPS .887）、...
  守備端（投手）：陳柏清（ERA 2.45）、...
```

**實作方式：**
1. 依球員姓名從 `pitchers_box.csv`、`lineups.csv` 取該球員**最近一場**的紀錄（ERA/WHIP/FIP/OPS 等欄位在該檔案中已是賽季累計值）
2. 組成與 `model_ready_games.csv` 相同格式的特徵向量
3. 用已訓練的 RF / LR 模型推論（存成 pkl）
4. 用 SHAP 對單筆預測做解釋，輸出前三大因素

## 八、環境建置（給尚未設定環境的組員）

```bash
# 1. 克隆/取得專案資料夾後，進入目錄
cd <專案路徑>

# 2. 建立虛擬環境
python -m venv .venv

.venv\Scripts\activate        # Windows
source .venv/bin/activate      # macOS / Linux

# 4. 安裝所有相依套件
pip install requests pandas scikit-learn matplotlib shap

# 5. 若要使用 Streamlit UI
pip install streamlit
```
